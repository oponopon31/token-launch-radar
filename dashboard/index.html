How implied value is computed

Every row is scored by one function of the snapshot figures. No protocol name is special-cased, and no row is hand-picked.

Growth is the 7-day TVL change, clamped to −80…300% and dampened with tanh, so a hot week lifts a protocol but never doubles it. Maturity grows from 0.75 toward 1.10 over about 540 days of running with no token; a protocol with no listing date is scored as 365 days old. Breadth adds 4% per extra chain, up to 5 extra chains.

Calibration — where each category multiple comes from

For each category, the multiple is the median market-cap-to-TVL ratio of the live-token protocols in that category, each ratio winsorised to 0.001…3, then shrunk toward the global median with strength 5.
